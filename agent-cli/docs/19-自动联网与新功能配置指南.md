# 自动联网与新功能配置指南

本文档说明如何配置 Frees Agent 的新能力：

- 自动联网检索（Tavily）
- 模型自动回退（Ollama / LM Studio / MCP / 云端）
- 跨设备 memory/sessions 自动合并
- 对话自动压缩与 token 预算控制
- 规划层、反思层、任务记忆、向量记忆

## 2. 自动联网检索

当用户问题包含“最新/今天/news/latest”等时，聊天会自动尝试联网检索（Tavily）。

前提：

1. 已配置 `TAVILY_API_KEY`
2. `tools.webSearch.enabled = true`

## 3. 模型自动回退

`conversation.autoProviderFallback = true` 时，系统会按可用性自动探活并回退 provider。

默认优先顺序：

1. `ollama`
2. `openai-compatible`（LM Studio / vLLM 等）
3. `mcp`
4. `anthropic`

也可以通过命令行控制：

```bash
frees-agent chat . --auto-provider
frees-agent chat . --no-auto-provider
```

## 4. memory/sessions 跨端合并

跨设备自动合并读取：

- 打开 `memory.autoMergeAcrossDevices`
- 在 `memory.syncRoots` 中配置共享目录

只在当前设备写入（推荐）：

- `memory.syncWritesToRoots = false`

写入同步到所有根目录（高级场景）：

- `memory.syncWritesToRoots = true`

手动触发一次合并：

```bash
frees-agent memory merge
```

## 5. 自动压缩对话与防止上下文膨胀

关键参数：

- `maxOutputTokens`: 单次回答上限
- `summarizeAfterMessages`: 消息条数阈值
- `maxRecentContextTokens`: 近消息 token 预算阈值（建议本地模型设为 2000~3200）
- `maxHistoryMessages`: 发送给模型的最大历史消息条数
- `hardContextCap`: 历史上下文硬上限，避免配置过大导致 4k 上下文模型被打爆
- `autoContinueOnCutoff`: 截断时自动续写

另外，最新版本已加入以下保护：

- 自动过滤空内容或异常 assistant 历史消息，避免 `assistant must not be empty`
- 空回复兜底文案不会写入长期记忆，避免污染 memory/session
- 对 Qwen3 系列 OpenAI 兼容请求自动附带 `chat_template_kwargs.enable_thinking=false`，减少“只输出思考过程”问题

## 6. 规划层与反思层

- `planningEnabled = true`：回答前先产出执行计划
- `reflectionEnabled = true`：回答后做自检和修正

## 7. 向量记忆与任务记忆

存储文件：

- `memory/vector-memories.json`
- `memory/task-memory.json`

作用：

- 向量记忆用于语义召回相关历史
- 任务记忆用于跟踪长期待办和状态
