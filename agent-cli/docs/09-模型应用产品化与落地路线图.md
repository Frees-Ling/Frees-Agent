# 模型应用、产品化与落地路线图

## 1. 不要只盯着训练

很多团队一谈 AI 就只想到“训练模型”，但真正决定产品是否好用的因素还包括：

- 模型选择
- 系统提示词
- 工作流设计
- 工具调用
- 记忆系统
- RAG
- 长对话压缩
- 权限控制
- 评测与监控

## 2. 从小到大的落地路线

### 第一阶段

- 先选一个可用模型
- 先把聊天、问答、简单代码能力跑通

### 第二阶段

- 加工作区上下文
- 加代码搜索
- 加文件编辑
- 加多轮对话

### 第三阶段

- 加长期记忆
- 加用户画像
- 加长对话摘要
- 加项目级知识

### 第四阶段

- 加 RAG
- 加工具路由
- 加评测集
- 加权限管理

### 第五阶段

- 微调模型
- 域内数据增强
- 多模型路由
- 自动化运维

## 3. Frees Agent 的位置

`Frees Agent` 现在已经具备：

- 聊天
- 代码理解
- Agent 式代码编辑
- 本地模型和云端模型接入
- 记忆
- 长对话
- 中文文档区

下一步很自然的增强方向就是：

- RAG
- 向量检索
- 更强的权限系统
- 电脑控制工具
- 多智能体协作
