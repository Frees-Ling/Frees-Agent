# 训练模型常见问题与解决方案

## 1. 模型学不会，效果很差

常见原因：

- 数据太少
- 数据太脏
- 学习率不合适
- 训练轮数不够
- 训练目标不清晰

解决建议：

- 先检查数据质量
- 先缩小任务范围
- 先用小数据做验证
- 调整学习率和 batch size

## 2. 模型过拟合

表现：

- 训练集很好
- 验证集变差
- 泛化能力下降

解决建议：

- 加验证集监控
- 降低训练轮数
- 提前停止
- 提高数据多样性

## 3. 灾难性遗忘

表现：

- 新任务提升了
- 原本会的能力反而退化了

解决建议：

- 混入通用数据
- 保留原能力样本
- 降低学习率
- 控制微调强度

## 4. 显存不够

解决建议：

- 用 LoRA / QLoRA
- 减小 batch size
- 开启梯度累积
- 使用更小模型
- 使用量化训练方案

## 5. 模型输出变乱、答非所问

可能原因：

- 数据风格混乱
- 指令模板不统一
- 多轮样本构造质量差

解决建议：

- 统一 prompt 模板
- 统一输出风格
- 清理异常样本

## 6. 训练完模型还是不够实用

这很常见。

原因通常不是模型“太笨”，而是系统设计不完整。

解决建议：

- 加 RAG
- 加工具调用
- 加记忆系统
- 加长对话摘要
- 加用户画像
- 加工作流控制

一句话：
很多“模型问题”，其实是“产品系统问题”。
