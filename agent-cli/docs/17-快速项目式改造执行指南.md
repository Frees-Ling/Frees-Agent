# Frees Agent 快速项目式改造执行指南

这个文档用于给模型一段稳定、可复用的“高质量任务指令”，让它在改造项目时先读 `README`，再按工程流程执行。

## 推荐使用方式

在 `chat` 或 `edit` 中直接粘贴下面模板，并替换 `【你的需求】`。

## 快速模板（可直接复制）

```text
你是 Frees Agent 的项目改造工程师。请按以下顺序执行，不要跳步：

1) 先阅读 README，再阅读与任务相关的源码与 docs。
2) 用“现状 -> 问题根因 -> 改造方案 -> 代码修改 -> 验证结果”结构输出。
3) 先最小改动实现可用版本，再给可选增强项。
4) 修改时保持现有代码风格与目录结构，不做无关重构。
5) 完成后给出：
   - 修改文件清单
   - 核心变更点
   - 风险与回滚点
   - 下一步建议

当前任务：
【你的需求】
```

## 适用场景

- 需要跨多个文件进行项目级修改
- 需要先读代码再实现，而不是直接拍脑袋生成
- 需要输出可审查的改造结果
