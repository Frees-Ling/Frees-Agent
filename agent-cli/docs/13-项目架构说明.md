# Frees Agent 项目架构说明

## 1. 架构目标

`Frees Agent` 的目标不是做成一次性脚本，而是做成一个可以持续维护和拓展的终端 AI Agent 工程。

所以项目结构强调：

- 命令清晰
- 模型清晰
- 记忆清晰
- 工作区能力清晰
- 扩展点清晰

## 2. 核心分层

### 命令层

负责：

- 解析参数
- 调用服务
- 输出结果

目录：

- `src/commands/`

### 能力层

负责：

- 模型接入
- 工作区扫描
- 记忆
- skill
- 系统能力

目录：

- `src/model/`
- `src/workspace/`
- `src/memory/`
- `src/skills/`
- `src/system/`

### 展示层

负责：

- banner
- 状态输出
- 交互提示

目录：

- `src/ui/`

## 3. 为什么这样拆

如果以后你要继续增加：

- RAG
- 多智能体
- IDE 集成
- 电脑控制
- 更强权限系统

这种结构会比把所有逻辑堆在一个文件里更容易维护。
