# 什么是 LLM 模型与 AI 智能体

## 1. 什么是 LLM

LLM 是 Large Language Model，也就是“大语言模型”。

它本质上是一个通过海量文本数据训练出来的概率模型。给它一段输入，它会根据上下文预测下一段最可能的内容。现代 LLM 不只是“补全句子”，还具备：

- 语言理解
- 文本生成
- 代码生成
- 结构化推理
- 工具调用
- 多轮对话

常见模型包括：

- Qwen
- Llama
- Mistral
- DeepSeek
- Claude
- GPT 系列

## 2. 什么是 AI Agent

AI Agent 可以理解成“有目标、有步骤、会使用工具的模型执行体”。

普通聊天模型往往只是：

- 你问一句
- 它答一句

而 Agent 会更进一步：

- 理解目标
- 制定步骤
- 读取文件
- 搜索代码
- 调用工具
- 修改代码
- 根据结果继续下一步

所以 Agent = 模型 + 工具 + 工作流 + 状态 + 记忆。

## 3. LLM 和 Agent 的关系

可以把它理解为：

- LLM 是“大脑”
- Agent 是“大脑 + 手 + 记忆 + 任务执行系统”

没有工具和状态时，模型通常只是“会说”。
有了 Agent 框架以后，它才更像“会做事”。

## 4. 一个好用的代码 Agent 应该具备什么

一个真正好用的代码类 Agent，至少应该具备：

- 能读取整个工作区
- 能搜索代码
- 能理解文件之间的关系
- 能修改文件
- 能持久化记忆
- 能处理超长对话
- 能保留用户画像和用户偏好
- 能切换本地模型和云端模型

`Frees Agent` 的设计方向，就是朝这个目标演进。
