# 数据集构建、清洗、标注与评测

## 1. 为什么数据集决定上限

模型训练里，真正决定效果上限的，通常不是“你有没有最贵的 GPU”，而是：

- 数据是不是干净
- 数据是不是贴近目标任务
- 标注是不是一致
- 评测是不是靠谱

## 2. 数据集从哪里来

常见来源包括：

- 自己业务里的真实问答或工单
- 历史代码提交与评审记录
- 内部知识库
- 公开高质量数据集
- 人工编写的指令样本

## 3. 数据清洗要做什么

- 去重
- 去 HTML 噪音
- 去乱码
- 去无意义重复
- 去错误标签
- 去互相矛盾样本
- 去泄露敏感信息的数据

## 4. 标注时要统一什么

- 指令风格
- 输出格式
- 语气
- 是否允许解释
- 是否允许思维过程外露
- 代码输出规范

## 5. 评测一定要做

至少要有三类评测：

- 自动评测
- 人工抽样评测
- 回归评测

如果是代码模型，还建议增加：

- 编译成功率
- 单元测试通过率
- 指令遵循率
- bug 引入率

## 6. 对 Frees Agent 用户最实用的建议

如果你以后要训练一个更懂你自己的模型，最有价值的数据往往不是“网上随便抓来的大堆文本”，而是：

- 你真实写过的代码
- 你真实问过的问题
- 你希望模型遵守的输出风格
- 你在项目中反复使用的工作流
