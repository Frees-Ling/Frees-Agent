# 系统权限、电脑控制与安全边界

## 先说最重要的事

`Frees Agent` 不应该偷偷获得系统权限。

如果未来你要让它拥有更强的电脑操作能力，比如：

- 控制鼠标键盘
- 控制其他应用
- 读取更多系统文件
- 执行更高权限脚本

那么正确做法一定是：

- 手动授权
- 明确告知
- 明确范围
- 明确日志

## macOS 常见权限

### 1. 辅助功能

适合：

- 控制键盘和鼠标
- 自动化操作界面

### 2. 自动化

适合：

- 控制其他应用
- 让一个应用驱动另一个应用

### 3. 完全磁盘访问权限

适合：

- 读取更多系统级文件
- 跨更多目录访问数据

## Windows 常见权限

### 1. 麦克风 / 摄像头 / 隐私权限

适合：

- 语音输入
- 音视频能力

### 2. PowerShell 执行策略

适合：

- 运行脚本
- 自动化任务

### 3. 管理员权限

适合：

- 更高风险的系统级操作

但不应该默认长期使用。

## 推荐原则

- 默认最小权限
- 能不提权就不提权
- 每一种高权限能力都要单独开关
- 所有高风险动作都要有日志
- 给用户留撤销权限的路径
