# Frees-Agent 不足之处与改进计划

本文档记录当前版本的已知不足、待优化项和长期改进路线，作为自主迭代的 roadmap。

## 一、功能缺失

### 1.1 多模态能力 ❌
- 无法读取/分析图片（无 Vision API 集成）
- 无法处理视频文件
- 无法处理音频/语音输入输出
- **目标**：支持图片理解、视频帧提取分析、语音对话

### 1.2 工具生态 ✅ 持续扩展中
- 已有基础文件读写、bash、web_fetch 工具
- ✅ MCP 配置模板已提供（FFmpeg/Pillow/Puppeteer/PostgreSQL 等）
- 需用户自行安装对应 MCP 服务器才能使用
- **下一步**：内置 ffmpeg 封装工具，无需额外 MCP 服务器

### 1.3 自主运行能力 ✅ 大幅增强
- ✅ 规划器支持多步任务分解（DAG 子任务 + 结构化步骤跟踪）
- ✅ 后台任务队列/调度机制（`src/tasks/queue.js`）
- ✅ 工具循环集成步骤进度回调
- **目标**：支持自主任务分解、执行、验证循环

## 二、技术债务

### 2.1 测试覆盖
- 61 个测试通过，覆盖工具层和基础功能
- ❌ 无端到端聊天测试
- ❌ 无记忆系统 Mock 测试
- **目标**：测试覆盖 >80%

### 2.2 错误处理 ✅ 已改进
- ✅ HTTP 请求状态码分类处理（401/403/404/429/5xx）
- ✅ 各状态码附带可操作的修复建议
- ✅ 联网搜索 API Key 缺失提示申请地址
- ✅ 模型返回异常格式重试策略（连续失败>=3 次自动中止并返回友好提示）
- ✅ 配置文件解析错误提示友好化（含具体 JSON 解析错误信息）

### 2.3 性能
- 工作日索引 24MB 预算硬编码
- 向量搜索为纯内存实现，大规模记忆时 OOM 风险
- 无缓存层，重复查询每次都重新嵌入
- **目标**：分层缓存 + 可配置预算
